# Shadertoys the coverage table is measured over, by id.
#
# The shaders themselves are not here and will not be: Shadertoy's default
# licence is CC BY-NC-SA 3.0 unless the author says otherwise, so what this
# repository can hold is the list. shadertoy-fetch turns it into files
# under Corpus/External, which .gitignore keeps out.
#
# A line is one id - the tail of https://www.shadertoy.com/view/<id> - and
# everything after a # is a comment. A shader with buffers becomes several
# files from the one id.
#
# This list is deliberately empty. Filling it is a choice about which shaders
# to measure, and it belongs to whoever is doing the measuring: pick from
# Shadertoy's own listings, and prefer breadth over fame, since what the counts
# rank is how many shaders a gap blocks rather than how good they are.
#
# For example:
#
#   Ms2SD1     # Seascape
#   XsXXDn     # Creation
